Neon Drift creates digital art through code. The software generates glowing lines that drift across your screen. You control the shapes and the colors. ## 💻 What this software does

This tool uses math to build art. You do not need to draw lines by hand. The engine calculates the path and glow of each element. You pick from three shape modes to change the look of your canvas. The result is modern, neon-style art. Artists use these patterns to decorate apparel or create backgrounds.

## 🕹️ Using the controls

The interface is simple. You will see buttons at the bottom of your screen. These buttons manage the art.

*   Spacebar: Generates a new set of glowing lines.
*   Mode 1: Sets the lines to circular paths.
*   Mode 2: Sets the lines to jagged, angular paths.
*   Mode 3: Sets the lines to smooth, wavy paths.
*   Color Toggle: Switches between preset color palettes.

The lines drift in real time. If the animation looks slow, close other programs to free up memory on your computer.
